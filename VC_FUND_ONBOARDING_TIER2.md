# Tier 2 VC Fund Onboarding (SaaS)

## Goal
Bring a mid-market VC fund online with full document synchronization, decision logging, and analytics readiness within 7–14 days.

## Onboarding Phases

### Phase 1: Fund Setup (Day 0–1)
- Create fund profile (name, type, website).
- Confirm organization access (MD/Admin).
- Assign roles (partner, principal, associate, analyst).

### Phase 2: Data Synchronization (Day 1–4)
**Primary integrations:**
- Google Drive: IC memos, LPAs, portfolio updates.
- ClickUp: deal pipeline, IC tasks, follow-ups.

**Manual uploads:**
- Investor updates, PDF decks, and spreadsheets.

### Phase 3: Knowledge Foundation (Day 4–7)
- Normalize source tags (sector, stage, region).
- Create a baseline decision log for last 12 months.
- Validate sources with 3–5 test queries.

### Phase 4: Analytics & Decision Engine (Day 7–14)
- Ensure 5+ decisions logged for analytics activation.
- Review sector and stage conversion rates.
- Track partner win rates and decision velocity.

## Recommended Docs
- IC memos and decision notes
- LPAs, fund thesis, mandate
- Portfolio updates and KPI reports
- Pipeline exports / CRM snapshots
- Partner meeting notes

## Success Criteria
- 80%+ of active pipeline docs synced
- 100% of new IC decisions logged
- Decision Engine dashboards populated

## Tips
- Start with 10–15 high-value documents
- Invite 2–3 team members first
- Use tags to improve retrieval quality
